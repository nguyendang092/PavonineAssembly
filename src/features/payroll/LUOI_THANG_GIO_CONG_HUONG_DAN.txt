3. FIREBASE — CẤU TRÚC DỮ LIỆU
================================================================================

Đường dẫn gốc (mặc định):
  attendance/{YYYY-MM-DD}/

Đường dẫn Korean:
  koreanAttendance/{YYYY-MM-DD}/

Ví dụ:
  attendance/2026-08-19/emp_abc123
  attendance/2026-08-19/_meta

3.1. Bản ghi nhân viên (mỗi ngày)
---------------------------------
Khóa RTDB (PAYROLL_EMP trong payrollEmployeeFields.js):

  stt              — Số thứ tự
  mnv              — Mã nhân viên
  mvt              — Mã vị trí
  hoVaTen          — Họ tên
  boPhan           — Bộ phận
  maBoPhan         — Mã bộ phận
  ngayVaoLam       — Ngày vào làm
  ngayHopDong      — Ngày hợp đồng
  gioVao           — Giờ vào (loại phép / BGC / giờ thực)
  gioRa            — Giờ ra
  caLamViec        — Ca (S1, S2, …)
  loaiPhep         — Loại phép
  tangCaTrua       — TC trưa (giờ)
  tangCaTaiXePhut  — TC tài xế (phút)
  duocNghiBu       — Được nghỉ bù (yes/no)

Cờ payroll (merge từ _meta, KHÔNG lưu trực tiếp trên row):
  payrollEarlyOtPaperwork
  payrollLateOtExcluded
  payrollNightOtPaperwork

3.2. Meta ngày (_meta)
----------------------
  attendance/{dateKey}/_meta

  isOffDay            — Ngày off
  isHolidayDay        — Ngày lễ
  isCompensatoryDay   — Ngày nghỉ bù (NB)
  earlyOtPaperwork    — Map { employeeId: boolean } — TC sớm có giấy tờ
  lateOtPaperwork     — Map { employeeId: boolean } — loại trừ TC muộn
  nightOtPaperwork    — Map { employeeId: boolean } — TC ca đêm có giấy tờ

3.3. Khóa dòng trên lưới tháng (rowId)
--------------------------------------
  - Thường = MNV
  - Trùng MNV nhiều bản ghi Firebase → "{mnv}__{firebaseId}"
  - Hằng: PAYROLL_MONTH_ROW_ID_SEP = "__"
  - Hàm: canonicalPayrollMonthRowId(), parsePayrollMonthRowIdParts()
  - File: payrollMonthlyGridData.js

4.1. Kích hoạt load
-------------------
Trong PayrollMonthlyTimesheetModal.jsx:

  useEffect(() => {
    if (!open) return;
    void loadMonth();
  }, [open, loadMonth]);

loadMonth() cũng được gọi lại khi:
  - Đổi tháng (PayrollMonthNavigator → đổi monthRange.keys)
  - Lưu form điểm danh (AttendanceEmployeeFormModal onSaved)
  - Lưu off/lễ/NB (AttendanceOffHolidayDaysControl onSaved)
  - Bấm nút «Tải lại» trên modal

4.2. Hook usePayrollMonthDayChunks
----------------------------------
File: usePayrollMonthDayChunks.js

Input:
  monthKeys        — mảng ["2026-08-01", "2026-08-02", …, "2026-08-31"]
  attendanceRootPath — "attendance" hoặc "koreanAttendance"
  tlPage           — i18n

Output state:
  dayChunks          — mảng chunk đầy đủ (mới nhất)
  displayDayChunks   — useDeferredValue(dayChunks) — render mượt hơn
  loading            — đang tải batch đầu
  loadingMore        — đang tải batch tiếp
  isGridBusy         — loading || loadingMore || stale deferred
  error              — thông báo lỗi / tháng trống
  loadMonth()        — hàm refetch

Cơ chế:
  - Mỗi lần loadMonth: tăng loadSeqRef, reset dayChunks = []
  - Gọi fetchPayrollMonthDayChunks()
  - onFirstBatch: hiển thị batch đầu ngay (startTransition)
  - onAfterBatch: cập nhật dần từng batch
  - isStale(): hủy kết quả nếu user đổi tháng/đóng modal giữa chừng

4.3. fetchPayrollMonthDayChunks
-------------------------------
File: payrollMonthlyGridData.js

Pseudo-code:

  for (i = 0; i < monthKeys.length; i += 7) {
    batchKeys = monthKeys.slice(i, i + 7)
    batchResults = await Promise.all(
      batchKeys.map(dateKey =>
        get(ref(db, `${attendanceRootPath}/${dateKey}`))
          → buildPayrollMonthDayChunkFromRaw(snap.val(), dateKey)
      )
    )
    allChunks.push(...validBatch)
    applyPayrollMonthCanonicalKeysToChunks(allChunks)  // gán monthEmployeeKey
    onFirstBatch / onAfterBatch callbacks
    requestAnimationFrame yield giữa các batch
  }
  return allChunks

Lưu ý:
  - Dùng get() — KHÔNG onValue() → không realtime
  - Batch size = 7 ngày (PAYROLL_MONTH_FETCH_BATCH_SIZE)
  - Ngày không có dữ liệu VÀ không có _meta off/lễ/NB → chunk = null, bỏ qua

4.4. buildPayrollMonthDayChunkFromRaw
-------------------------------------
File: buildPayrollDayFromRaw.js

Input:  raw (object Firebase), dateKey ("2026-08-19")
Output: chunk object hoặc null

Cấu trúc chunk:

  {
    dateKey: "2026-08-19",
    employees: [...],           // slim records (PAYROLL_MONTH_SLIM_KEYS)
    baseEmployees: [...],       // full records (form edit, Excel)
    byId: Map(firebaseId → emp),
    byMonthEmployeeKey: Map(rowId → emp),
    rowLookup: Map(variant keys → emp),
    isOffDay: boolean,
    isHolidayDay: boolean,
    isCompensatoryDay: boolean,
    isPayrollOffLikeDay: boolean,
    earlyOtPaperworkById: { [id]: boolean },
    lateOtExcludedById: { [id]: boolean },
    nightOtPaperworkById: { [id]: boolean },
  }

Pipeline parse 1 ngày:
  parsePayrollDayFromAttendanceRaw(raw)
    → mergeAttendanceDayRowsFromRaw / reconcile
    → đọc _meta off/lễ/NB/OT paperwork
    → payrollEmployees (slim) + baseEmployees (full)

  12. TC đêm ngày lễ (×3.9)
  13. Giờ công ca ngày NB (×2.0)

  si=4  c27    coeff=2.7    — TC off ca đêm / TC đêm NB

7.1. Chuẩn bị dữ liệu ô (per employee)
--------------------------------------
Hàm: buildPayrollMonthEmployeeDayCells({ monthDayMeta, rep, rowId })
File: PayrollMonthlyTimesheetModal.jsx (dòng ~248)

Với mỗi ngày trong tháng:

  1. Lấy chunk = chunkByDate.get(dateKey)
  2. resolvePayrollMonthDayEmployee(chunk, rowId, rep)
     → tìm bản ghi NV trong chunk (qua rowLookup / byMonthEmployeeKey)
  3. Kiểm tra beforeJoin:
     isPayrollMonthDayCellBeforeJoinWithoutAttendance(dateKey, joinDate, emp)
     → ô trống trước ngày vào làm
  4. getPayrollMonthlyMainRowCell(emp, chunk)
     → { kind: "leave" | "hours" | "dash", ... }
  5. getPayrollMonthlyCoeffHoursMap(payrollOtDayParamsFromMonthChunkEmp(...))
     → Map hệ số → số giờ cho 6 dòng TC

Kết quả mỗi ô:
  { dateKey, chunk, baseBg, beforeJoin, emp, main, coeffMap }

7.2. Render ô (PayrollMonthlyTimesheetDayCell)
----------------------------------------------
Sub-row si=0 (main):
  - kind=leave  → badge loại phép (PN, NB, KL, …)
  - kind=hours  → số giờ công
  - kind=dash   → «-» (off/lễ/Chủ nhật không hiển thị GC ở dòng chính)

Sub-row si=1..6 (hệ số):
  - formatPayrollMonthlyCoeffSubrowDayCell(coeffMap, coeff)
  - Hiển thị giờ TC theo hệ số tương ứng

Tương tác:
  - Click ô → openDayCellEditor(dateKey, rowId)
  - Kiểm tra quyền: canEditPayrollMonthTimesheetGridCell()
  - Mở AttendanceEmployeeFormModal với buildPayrollMonthDayCellFormRecord()

7.3. Logic hiển thị đặc biệt (payrollMonthlyCoefficientBuckets.js)
-----------------------------------------------------------------
  - Chủ nhật: GC+TC gộp vào 1 dòng hệ số; dòng chính «-»
  - Ngày off/lễ: dòng chính «-»; giờ ở dòng hệ số
  - Ngày nghỉ bù (NB): tối đa 8h GC trên dòng chính; dư → ×2.0/×2.7
  - Ca đêm (S2): GC trên dòng chính; dòng ×0.3 hiển thị mã ca
  - BGC: badge «BGC» khi chưa có giờ vào
